# 📚 EIIStudy

Web gratuita para consultar y descargar apuntes y ejercicios universitarios, organizados por curso, semestre y asignatura.

🔗 **WEB:** `https://j4v13r98.github.io/EiiStudy/`

---

## 🤝 ¿Quieres ayudar? Aporta apuntes/ejercicios

Este repo es solo el código de la web. Para **subir o proponer apuntes/ejercicios**, dirígete al repositorio de contenido: [`EiiStudy-Storage`](https://github.com/j4v13r98/EiiStudy-Storage) y realiza un _pull request_ con los susodichos.

**NOTA:** Solo se admite **CONTENIDO PROPIO** (apuntes y ejercicios elaborados por cada uno), no material oficial del profesorado.
